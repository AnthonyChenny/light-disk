# Security policy / 安全策略

当前只维护最新 Beta；无长期支持承诺。light-disk 包含以 root 运行的受限辅助服务，处理真实磁盘，安全问题应优先报告。

请使用 GitHub 仓库 **Security → Advisories → Report a vulnerability** 私下报告。仓库管理员必须在 Settings → Security 中启用 Private vulnerability reporting 后此入口才可用；若尚未启用，请通过不含漏洞细节的 Issue 请求开启，不要公开可利用步骤、用户数据或凭据。本文件不声称已经启用了远端设置。

报告请提供版本、系统、最小复现条件、预期影响及脱敏日志。不要上传磁盘镜像或真实文件。发现数据安全异常请停止写入并保留独立备份。

Only the latest Beta is currently maintained. Report privately through **Security → Advisories → Report a vulnerability** once the repository owner enables Private vulnerability reporting. If unavailable, request activation in an issue without publishing exploit details. Include version, OS, a minimal reproducer, impact and sanitized logs; never upload user disks, file contents, secrets or passwords. Remote security settings have not been enabled merely by adding this file.
