# light-disk / 轻盘 0.1.3-beta.1

**普通用户只下载轻盘 DMG；首次使用还要先从官方安装 macFUSE。下面已提供两个直接下载链接，请按顺序操作。**

**End users only need the light-disk DMG. First-time users must install official macFUSE first; both direct downloads and ordered steps are below.**

## 首次安装：从下载到使用

**第一次使用，只需下载下面两个 DMG；不需要下载源码或其他附件。** macFUSE 是轻盘写入 NTFS 所需的底层组件，要先安装；NTFS-3G 已包含在轻盘安装包里，不用另找。

| 顺序 | 下载什么 | 点击下载 |
|---|---|---|
| ① | 官方 macFUSE 5.5.0，文件名 `macfuse-5.5.0.dmg` | [下载 macFUSE](https://github.com/macfuse/macfuse/releases/download/macfuse-5.5.0/macfuse-5.5.0.dmg)（[官方发布页](https://github.com/macfuse/macfuse/releases/tag/macfuse-5.5.0)） |
| ② | 轻盘 Beta，文件名 `light-disk-0.1.3-beta.1-arm64.dmg` | [下载轻盘](https://github.com/AnthonyChenny/light-disk/releases/download/v0.1.3-beta.1/light-disk-0.1.3-beta.1-arm64.dmg)（[本项目发布页](https://github.com/AnthonyChenny/light-disk/releases/tag/v0.1.3-beta.1)） |

### 第一步：安装 macFUSE

下载完成后，打开“访达 → 下载”，双击 `macfuse-5.5.0.dmg`，再双击里面的 **macFUSE 安装包（`.pkg`）**。按“继续 → 安装”完成，出现认证时在系统窗口输入 Mac 管理员密码或使用 Touch ID。如安装器要求重启，先重启再继续。已经装好 5.5.0 的用户可跳过重复安装。官方页面中的 `debug.tbz`、`sha256`、`sig` 和 `Source code` 都不是普通用户要安装的文件。

### 第二步：打开 macFUSE 的两个扩展

打开 **系统设置 → 通用 → 登录项与扩展 → 文件系统扩展**，启用 **macFUSE** 和 **macFUSE (local)**；优先使用“按类别”入口。轻盘使用 FSKit 模式，**不用进入恢复模式或降低启动安全性**。若找不到入口或开关无反应，见[完整安装指南](https://github.com/AnthonyChenny/light-disk/blob/main/docs/INSTALL.zh-CN.md#补充扩展开关没有反应)。

### 第三步：安装轻盘

双击 `light-disk-0.1.3-beta.1-arm64.dmg`，再双击里面的 **`安装轻盘.pkg`**，按“继续 → 安装”完成管理员认证。这一步会把轻盘放进“应用程序”，并安装 NTFS 引擎和辅助服务。不要只找一个 App 拖过去；也不需要重复下载独立 `.pkg`。

### 第四步：允许轻盘访问硬盘

打开 **系统设置 → 隐私与安全 → 完全磁盘访问权限**，点击 **`+`**，在文件选择窗口按 **`⌘⇧G`**，粘贴下面这条路径并回车：

```text
/Library/PrivilegedHelperTools/local.qingpan.helper
```

选中该文件，添加并打开开关。若系统要求认证，在系统窗口完成。首次启动轻盘若询问访问可移动卷，也请允许；可在“隐私与安全 → 文件与文件夹 → 轻盘 → 可移除的宗卷”核对。完全磁盘访问是较广的系统权限，请审核后决定。

### 第五步：打开轻盘，连接硬盘

从 **访达 → 应用程序 → 轻盘** 启动，点击屏幕顶部菜单栏的硬盘图标，再接入 NTFS 硬盘。等卡片显示 **“可读写”** 后，就能在 Finder 中双向复制、粘贴和拖放。拔线前先点击 **“推出”**，等提示可以拔线再断开。

**如果系统提示“无法验证开发者”或阻止打开：** 当前 Beta 是临时签名、尚未公证。确认下载来源后，在“系统设置 → 隐私与安全”审核并使用“仍要打开”（若系统提供）。没有此选项请停止并反馈，不要关闭 Gatekeeper 或 SIP。[详细排错、升级与卸载](https://github.com/AnthonyChenny/light-disk/blob/main/docs/INSTALL.zh-CN.md)

## First installation: download, install, then connect

**For a first-time setup, download only the two DMGs below. You do not need source code or other release attachments.** Install macFUSE first: it connects NTFS-3G to macOS. NTFS-3G is already included in the light-disk installer; there is no separate engine download.

| Order | File | Download |
|---|---|---|
| ① | Official `macfuse-5.5.0.dmg` | [Download macFUSE](https://github.com/macfuse/macfuse/releases/download/macfuse-5.5.0/macfuse-5.5.0.dmg) ([official release](https://github.com/macfuse/macfuse/releases/tag/macfuse-5.5.0)) |
| ② | `light-disk-0.1.3-beta.1-arm64.dmg` | [Download light-disk](https://github.com/AnthonyChenny/light-disk/releases/download/v0.1.3-beta.1/light-disk-0.1.3-beta.1-arm64.dmg) ([project release](https://github.com/AnthonyChenny/light-disk/releases/tag/v0.1.3-beta.1)) |

### Step 1: Install macFUSE

In **Finder → Downloads**, open `macfuse-5.5.0.dmg`, then double-click the **macFUSE `.pkg` installer inside**. Follow Continue → Install, and authenticate with your Mac administrator password or Touch ID in the system dialog. Restart first if the installer requests it. Skip reinstalling if 5.5.0 is already installed. You do not need `debug.tbz`, `sha256`, `sig` or `Source code` from the vendor's page.

### Step 2: Enable both macFUSE extensions

Open **System Settings → General → Login Items & Extensions → File System Extensions**. Enable **macFUSE** and **macFUSE (local)**, preferably through the “By Category” view. light-disk uses FSKit: **Recovery Mode and reduced startup security are not needed**. If the entry is missing or toggles do not respond, see the [full installation guide](https://github.com/AnthonyChenny/light-disk/blob/main/docs/INSTALL.en.md#if-extension-switches-do-not-respond).

### Step 3: Install light-disk

Open `light-disk-0.1.3-beta.1-arm64.dmg` and double-click **`安装轻盘.pkg`** (Install QingPan) inside. Follow Continue → Install and authenticate. This installs the App in Applications, together with the engine and helper. Do not just drag an App; you do not need a second standalone `.pkg` download.

### Step 4: Authorize disk access

Open **System Settings → Privacy & Security → Full Disk Access**. Click **`+`**, press **`⌘⇧G`** in the file chooser, paste this path and press Return:

```text
/Library/PrivilegedHelperTools/local.qingpan.helper
```

Select the file, add it and switch it on. Authenticate in the system dialog if needed. Also allow the App's removable-volume prompt, or check Privacy & Security → Files & Folders → 轻盘 → Removable Volumes. Full Disk Access is a broad system permission; review it before granting it.

### Step 5: Launch and connect

Open **Finder → Applications → 轻盘**, click its disk icon in the top menu bar and connect your NTFS drive. Wait for **`可读写`** (read/write ready), then copy, paste or drag files in Finder. Click **`推出`** (Eject) and wait for completion before unplugging.

**If macOS cannot verify the developer or blocks opening:** this Beta is ad-hoc signed and not notarized. Verify the download source, then review System Settings → Privacy & Security and use Open Anyway if offered. If unavailable, stop and report the issue; do not disable Gatekeeper or SIP. [Troubleshooting, upgrade and uninstall](https://github.com/AnthonyChenny/light-disk/blob/main/docs/INSTALL.en.md)

当前界面为中文，仅提供 Apple Silicon（M 系列）版本。临时签名、未经过 Apple 公证。完整实测 macOS 27.0.1；其他系统版本及另一台干净 Mac 首装待验证。请先用可丢弃文件测试，重要数据保留备份。

Chinese UI, Apple Silicon only, ad-hoc signed and not notarized. Full local validation used macOS 27.0.1; other versions and clean installation on another Mac remain unverified. Start with disposable data and keep separate backups.
