# light-disk / 轻盘 0.1.3-beta.1

## 中文

首次开源 Beta，面向愿意自行审核权限的 Apple Silicon Mac 测试用户。当前 App 为中文界面，中英文安装与使用文档齐全。

- NTFS 自动挂载读写，Finder 双向复制；其他常见格式使用系统支持。
- 原生菜单栏、磁盘详情、安全推出、约四卡片列表、可选登录启动。
- 使用 NTFS-3G 2026.9.28 + macFUSE 5.5.0 FSKit；不降低启动安全性。
- 新增公开仓库文档、许可证清单、源码补丁、构建/发布脚本和 CI。

**安装顺序：** 先从 [macFUSE 官方页](https://github.com/macfuse/macfuse/releases/tag/macfuse-5.5.0)安装 macFUSE → 在文件系统扩展中启用 macFUSE 与 macFUSE (local) → 打开 DMG 运行 `安装轻盘.pkg` → 在完全磁盘访问权限中允许 `/Library/PrivilegedHelperTools/local.qingpan.helper` 并允许 App 访问可移动卷 → 启动轻盘、连接硬盘。只有显示“可读写”才完成写入挂载。完整指南见仓库 `docs/INSTALL.zh-CN.md`。

**已知限制：** ad-hoc 临时签名、未经过 Apple 公证，其他用户可能遇到 Gatekeeper 拦截；仅提供 arm64。构建目标 15.4+，实测 macOS 27.0.1，其他版本与另一台干净 Mac 首装待验证。当前不含 BitLocker、自动修复、格式化或 Intel 支持。macFUSE 是独立官方依赖，不在本 DMG 内。

历史本机版本完成镜像大文件和两块 NTFS 实盘双向摘要检查；公开 Beta 尚不构成广泛稳定性验证。请先用可丢弃文件测试并保留重要数据备份。

## English

First public-source Beta for Apple Silicon testers who can review system permissions. The App currently uses a Chinese UI; complete Chinese and English installation/usage guides are included.

- Automatic NTFS read/write mounts with bidirectional Finder copies; native support for other common formats.
- Native menu bar, disk details, safe eject, approximately four visible cards and optional login startup.
- NTFS-3G 2026.9.28 with macFUSE 5.5.0 FSKit; no reduced startup security.
- Public docs, license inventory, source patch, build/release tooling and CI.

**Install order:** install macFUSE from its [official release](https://github.com/macfuse/macfuse/releases/tag/macfuse-5.5.0) → enable macFUSE and macFUSE (local) file system extensions → run `安装轻盘.pkg` from the DMG → grant Full Disk Access to `/Library/PrivilegedHelperTools/local.qingpan.helper` and removable-volume access to the App → launch and connect your disk. `可读写` means read/write ready. Full guide: repository `docs/INSTALL.en.md`.

**Limits:** ad-hoc signed, not notarized; Gatekeeper may block downloads. arm64 only. Deployment target 15.4+, locally tested macOS 27.0.1; other OS versions and clean installation on another Mac remain unverified. No BitLocker, automatic repair, formatting or Intel support. macFUSE is a separate vendor dependency and is not in the DMG.

Earlier local versions passed disposable-image large-file tests and round-trip hashes on two physical NTFS drives. This does not establish broad production stability. Test with disposable files and maintain independent backups.
